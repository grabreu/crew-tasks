# web

React SPA of [shared-todo](../README.md): Vite, TanStack Router (file-based routes), Tailwind CSS, Biome.

## Development

Requires the Node.js version in `.node-version` and pnpm (version pinned in `package.json`).

```bash
pnpm install
pnpm dev
```

The dev server runs at `http://localhost:3000`.

Other commands: `pnpm check` (Biome format + lint), `pnpm typecheck`, `pnpm build`.
